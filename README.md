# Soirée jeux

Trois jeux pour une soirée, avec :
- une **interface admin** pour régler les décomptes et les paramètres, et lancer les jeux ;
- un **écran public** qui affiche le décompte et le déroulement ;
- une **interface téléphone** où les invités s'inscrivent et jouent.

## Jeux

1. [Le Chemin](docs/jeu1-le-chemin.md) — cahier des charges validé, [maquette](docs/maquettes/le-chemin.html)
2. [Duel au Far West](docs/jeu2-duel-far-west.md) — cahier des charges validé, [maquette](docs/maquettes/duel-far-west.html)
3. À définir
